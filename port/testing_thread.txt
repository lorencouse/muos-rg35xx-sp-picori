Game Information
Title: The Legend of Zelda: The Minish Cap (Project Picori)
URL: https://github.com/lorencouse/tmc/tree/rg35xx-sp-audio-ui

Instructions:
Not ready to run. Copy your Minish Cap ROM to ports/picori as baserom.gba (USA), baserom_eu.gba or baserom_jp.gba. The first launch extracts assets from the ROM and takes about two minutes.

| Button | Action |
|--|--|
| D-pad | Move |
| A | Sword / confirm |
| B | Item / cancel |
| X | Extra item slot |
| Y | Load the selected save state |
| L1 | GBA L |
| R1 | GBA R |
| L2 | Save state to the next slot |
| R2 (hold) | Fast-forward |
| Start | Pause menu |
| Select | Select |
| Menu | Port settings overlay |
